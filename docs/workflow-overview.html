Village Run — App Workflow

Google 로그인부터 러닝 기록, 데이터 저장, 공유까지 전체 흐름을 한눈에 확인하세요.

🔐
인증
Authentication
Step 1
Google 로그인 버튼 클릭
앱 시작 화면에서 사용자가 "Google로 계속하기" 버튼을 탭
↓
Step 2
GoogleSignIn.signIn()
Flutter google_sign_in 패키지를 통해 Google OAuth 흐름 시작
GoogleSignIn().signIn()
↓
Step 3
Supabase signInWithIdToken()
Google ID Token을 Supabase Auth에 전달하여 세션 교환
supabase.auth.signInWithIdToken()
↓
Step 4
세션 발급 → 지도 화면 이동
JWT 세션 수신 후 앱 상태가 인증 완료로 전환되어 지도 화면으로 라우팅
  • onAuthStateChange 이벤트 수신
  • Navigator.pushReplacement → MapScreen
🏃
러닝 기록
Run Tracking
Step 1
"시작" 버튼 탭
지도 화면 하단 FAB 탭으로 러닝 세션 시작
↓
Step 2
GPS 스트림 시작
Geolocator 위치 스트림 구독, 노이즈 제거 필터 적용
  • 최소 이동 거리 3 m 필터
  • distanceFilter: 3 설정
↓
Step 3
경로 실시간 점선 표시
새 좌표가 추가될 때마다 지도 위 Polyline을 실시간 업데이트
  • Polyline 점선 스타일 렌더링
  • 카메라 자동 추적 (follow mode)
↓
Step 4
"종료" 버튼 탭
러닝 세션 종료, 마지막 좌표 기록 후 영역 계산 시작
↓
Step 5
경로 닫힘 + 영역 계산
경로 유형을 감지하여 적합한 알고리즘으로 면적 계산
루프 감지 (≤ 20 m)
시작점 ↔ 끝점이 20 m 이내 → 폴리곤으로 닫고 Shoelace 공식으로 면적 계산
직선 경로
경로 길이 × 10 m 버퍼 적용하여 면적 추정
↓
Step 6
GeoJSON 생성
경로 및 영역 폴리곤을 표준 GeoJSON Feature 포맷으로 직렬화
{ "type": "Feature", … }
💾
데이터 저장
Storage
Step 1
runs 테이블 INSERT
Supabase PostgreSQL에 러닝 레코드 저장
  • path — 좌표 배열 (jsonb)
  • territory_geojson — 영역 GeoJSON (text)
  • distance_m — 총 거리 (m)
  • area_m2 — 영역 면적 (m²)
↓
Step 2
upsert_user_territory() RPC
PostGIS 기반 서버 함수 호출로 누적 영역 갱신
supabase.rpc('upsert_user_territory')
  • ST_Union으로 기존 영역과 신규 합산
  • user_territory 테이블 upsert
  • conflict_target: user_id
↓
Step 3
지도에 파란 오버레이 추가
저장 완료 후 지도 위에 사용자 누적 영역을 파란 반투명 폴리곤으로 렌더링
  • fill color: #4285F4 @ 30% opacity
  • stroke: #4285F4 @ 80% opacity
  • Polygon / MultiPolygon 모두 지원
📤
공유
Share
Step 1
기록 화면 → 공유 버튼 탭
러닝 결과 카드에서 공유 아이콘 탭
↓
Step 2
공유 URL 생성
사용자 ID를 포함한 딥링크 URL 조합
village-run-app.web.app/share/{userId}
↓
Step 3
Share.share() 호출
Flutter share_plus 패키지로 OS 기본 공유 시트 표시
Share.share(url, subject: '...')
↓
Step 4
브라우저에서 열기
수신자가 링크를 탭하면 모바일 브라우저에서 웹 앱 로딩
↓
Step 5
Firebase Hosting → index.html
Firebase Hosting이 SPA index.html을 서빙, 클라이언트 라우팅 처리
  • rewrite rule: /** → index.html
↓
Step 6
Supabase REST API 조회
userId 기준으로 runs 및 user_territory 데이터 fetch
GET /rest/v1/runs?user_id=eq.{id}
↓
Step 7
Leaflet.js 지도 + 카드 리스트
조회 데이터를 기반으로 인터랙티브 지도와 기록 카드 리스트 렌더링
  • Leaflet.js — 영역 폴리곤 지도 표시
  • 기록 카드: 날짜, 거리, 면적
  • 반응형 웹 레이아웃

Tech Stack

Flutter Supabase PostgreSQL PostGIS Firebase Hosting Leaflet.js Google Sign-In share_plus
